# 짤서랍

**말은 짧게, 짤은 찰지게!**

한국 예능·드라마 짤을 상황과 말투로 검색하는 정적 웹 서비스입니다.

- [서비스 열기](https://kittyinboots7.github.io/jjal-drawer/)
- 자연어 검색과 관계·말투 기반 후보 정렬
- 한국 예능·드라마 72개 프로그램, DB 2,294개 항목
- 사진과 움직이는 짤을 분리하고 결과를 3개씩 표시
- 홈 추천 한 장, 사용 상황 설명, 바로 복사, 브라우저 보관함

## 로컬 실행

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 여세요. 별도 API 키는 필요하지 않습니다. 첫 검색 시 외부 CDN에서 약 118MB의 다국어 AI 모델을 받습니다. 모델을 사용할 수 없으면 상황 키워드 검색으로 동작합니다.

## 구성

- `index.html`, `style.css`, `app.js`: 웹 화면
- `search.js`, `usage-query.js`: 검색 및 용도·말투 구분
- `ai-worker.js`: 브라우저 안에서 문장 임베딩 실행
- `catalog.json`, `vectors.bin`: 기본 검색 목록과 의미 검색 벡터
- `everyday-replies.json`: 일상 긍정·수락·실행 독려 용도 보강, 추가 짤과 의미 검색 벡터
- `home-picks.js`: 홈 추천 사용 상황
- `stills/`: 출처가 기록된 정지 컷

## 데이터와 한계

제목·태그·원본 주소는 [짤봇 공개 API](https://jjalbot.com/en/docs)와 출처가 확인된 [오늘의짤방](https://www.jjalbang.today/) 자료에서 수집했습니다. 일부 방송 캡처는 해당 방송을 다룬 공개 기사에서 확인했으며 출처 URL을 항목에 기록했습니다. 각 항목의 `sourceUrl`에 출처가 있습니다. 대부분 원본 서버에서 불러오고 일부 정지 컷을 포함합니다. **저장소 공개는 방송 화면·짤의 저작권이나 재사용 권한을 부여하지 않습니다.** 개별 미디어의 권리는 원 권리자에게 있으며 재사용 권한은 확인되지 않았습니다.

프로그램·용도·말투는 제목·태그와 내부 OCR을 바탕으로 추정합니다. 오분류나 오독이 남을 수 있습니다. 움직임 미확인 9개는 검색에서 제외합니다.

보관함은 브라우저의 localStorage에 저장됩니다. 계정 간·기기 간 동기화는 제공하지 않습니다. 검색문과 보관함은 브라우저 안에서 처리하고, 이미지와 AI 모델을 불러올 때 외부 서비스에 접속합니다.

## 배포

GitHub Pages에서 `main` 브랜치의 저장소 루트를 배포할 수 있습니다. `.nojekyll`을 포함하므로 빌드 과정이 필요하지 않습니다.

일상 표현 24개에 각 3개의 정지 짤 후보를 연결했습니다. 유사 표현 간 후보를 공유하며, 자막 일치와 장면·표정 기반의 맥락 매칭을 함께 사용합니다. `everyday-replies.json`의 `phrasePacks`에서 후보와 검수 메모를 확인할 수 있습니다. 정지 컷에는 원본 주소와 출처를 기록했습니다.
